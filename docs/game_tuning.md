# 戏本体改动确认表

> 用法：在每张表的 **「你填」** 列写你的值；**留空 = 用「建议值」**。
> 填完把这个文件发我，我照着改 `game_core.sv` / `sprite_render.sv` / `tb_game_core.sv`。
> 单位约定：像素 = 320×240 内部坐标；帧 = 60Hz 的一帧（≈16.7ms）；tick = 游戏逻辑节拍（也按 60Hz）。

---

## 表 1　核心玩法参数（已有，微调）


| 项目                 | 含义                                 | 建议值        | 你填                                                                     |
| -------------------- | ------------------------------------ | ------------- | ------------------------------------------------------------------------ |
| `PLAYER_SPEED`       | 玩家每帧移动像素                     | 2             |                                                                          |
| `BULLET_SPEED`       | 玩家子弹每帧上移像素                 | 5             |                                                                          |
| `MAX_PLAYER_BULLETS` | 屏幕最多同时几颗玩家子弹（现在是 1） | 3             | 我们打算玩家飞机一直射子弹，因为负责射击的手势不好确定，这项不做设置上限 |
| `FIRE_COOLDOWN`      | 两次发射最小间隔（帧）               | 11（≈190ms） |                                                                          |
| `ENEMY_MOVE_PERIOD`  | 敌机每多少 tick 移动一次             | 30（=0.5s）   |                                                                          |
| `ENEMY_STEP_X`       | 敌机每次横移像素                     | 4             |                                                                          |
| `ENEMY_DROP_Y`       | 敌机触左右边后下移像素               | 12            |                                                                          |
