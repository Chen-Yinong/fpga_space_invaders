## 1. 总体架构

```
                +--------------------------------------------------------------+
                |                      FPGA (7 Series)                         |
                |                                                              |
  DVP 摄像头     |  +-----------+   +-------------+   +------------------+      |
  640x480@30 ---|->| cam_      |   | axis_async_ |   | vision_pipeline  |      |
  PCLK/VSYNC    |  | capture   |-->| fifo        |-->| 灰度/降采样/分割 |      |
  HREF/D[7:0]   |  | (pclk域)  |   | (pclk->sys) |   | 形态学/质心/开合度|     |
                |  +-----------+   +-------------+   +---------+--------+      |
                |                                              | feat_*        |
  SCCB/I2C -----|-> I2C master (配置摄像头寄存器)                 v              |
                |                                    +------------------+       |
                |                                    |  gesture_fsm     |       |
                |                                    | 去抖/迟滞/冷却    |       |
                |                                    +--------+---------+       |
                |                                       cmd_valid/cmd[3:0]      |
                |                                              v              |
                |  +----------------+   +----------------------------------+    |
                |  | axi_lite_regs  |<->|           game_core              |    |
                |  | 阈值/状态/回读  |   | 玩家/子弹/敌机/并行碰撞/计分/LFSR |    |
                |  +----------------+   +----------------+-----------------+    |
                |                                       | 游戏状态(信箱同步)     |
                |                                       v                     |
                |  +-------------+   +----------------------------------+       |
                |  | vga_timing  |-->|          sprite_render           |       |
                |  | x/y/hs/vs   |   | 精灵 ROM/字符/行缓冲/双缓冲        |       |
                |  +-------------+   +----------------+-----------------+    |
                +---------------------------------------|----------------------+
                                                        v
                                          R[3:0] G[3:0] B[3:0] HS VS  ->  VGA 显示器
                                                        (640x480@60)
```

## 2. 模块划分与职责

| 模块 | 时钟域 | 职责 | 主责 | 关键输入 | 关键输出 |
| --- | --- | --- | --- | --- | --- |
| `cam_capture` | `pclk` | 采集 DVP 时序，输出 AXI4-Stream 视频流 | A | `pclk/vsync/href/data[7:0]` | `m_axis_tdata/tuser/tlast/tvalid` |
| `axis_async_fifo` | 跨域 | 视频流跨时钟域 | A | `clk_pix` 侧流 | `clk_sys` 侧流 |
| `vision_pipeline` | `clk_sys` | 灰度化、2×2 降采样、帧差/肤色分割、形态学、质心与面积统计 | B | 视频流 | `feat_cx/cy/area/w/h/open/vx`, `feat_valid` |
| `gesture_fsm` | `clk_sys` | 四种手势判定、去抖、迟滞、冷却 | B | `feat_*`, 阈值寄存器 | `cmd_valid`, `cmd[3:0]` |
| `game_core` | `clk_sys` | 玩家/子弹/敌机状态、并行碰撞判定、计分、关卡 | C | `cmd_*`, `tick_60hz` | 游戏状态向量 |
| `sprite_render` | `clk_pix` | 精灵 ROM 查表、字符叠加、行缓冲/双缓冲 | C | 游戏状态、像素坐标 | `rgb[23:0]`, `pixel_valid` |
| `vga_timing` | `clk_pix` | VGA 640×480@60 时序发生器 | A | `rst_n` | `x/y/hsync/vsync/video_active` |
| `axi_lite_regs` | `clk_sys` | 配置与状态寄存器（阈值在线标定） | A | `s_axi_*` | 寄存器总线 |
| `i2c_master` / `sccb_cfg` | `clk_sys` | 配置摄像头寄存器 | A | 配置命令 | `scl/sda` |

**端口契约与位宽定义**见 [`docs/interface_spec.md`](interface_spec.md) 第 8 节。

## 3. 数据流与时钟域

```
 [摄像头] --pclk域--> cam_capture --AXI4-Stream--> axis_async_fifo --clk_sys--> vision_pipeline
                                                                                   |
                                                                            feat_* (信箱同步)
                                                                                   v
                                        axi_lite_regs <---阈值---> gesture_fsm <---+
                                                                      |
                                                             cmd_valid / cmd[3:0]
                                                                      v
                                                                  game_core
                                                                      |
                                                        游戏状态 (信箱同步 clk_sys->clk_pix)
                                                                      v
                                     vga_timing ---> sprite_render ---> [VGA 显示器]
```

| 时钟域 | 频率 | 包含模块 |
| --- | --- | --- |
| `clk_sys` | 100 MHz | `axis_async_fifo`（读侧）、`vision_pipeline`、`gesture_fsm`、`game_core`、`axi_lite_regs` |
| `pclk` / `clk_pix` | 25.2 MHz | `cam_capture`、`axis_async_fifo`（写侧）、`vga_timing`、`sprite_render` |

**CDC 原则（详见 `interface_spec.md` 5.4）**

- 视频流：异步 FIFO。
- 多比特特征/状态：**数据寄存器 + 单比特 valid 同步**（信箱）。
- 单比特命令：`cmd_valid` 展宽 + 双触发器同步，配合独热 `cmd[3:0]`。

## 4. 关键设计决策

| 决策 | 选择 | 理由 | 备选 |
| --- | --- | --- | --- |
| 手势方案 | 传统视觉特征 + 小型决策器 | 7 Series 资源可承受、延迟可控、可解释 | 轻量 CNN（仅作为扩展项） |
| 视觉算法位置 | **全部在 PL** | 体现 FPGA 核心价值，避免"PS 跑 OpenCV" | 无 |
| 移动手势判别 | 质心位置 + 迟滞 | 稳定、易去抖、可连续控制 | 挥手计数（易抖动） |
| 射击手势判别 | 张开度下降沿 | 与移动特征正交，可同时操作 | 位置触发（会与移动冲突） |
| 命令编码 | 独热 + 单比特 valid | 跨时钟域安全、ILA 易读 | 二进制编码（有毛刺风险） |
| 碰撞判定 | 并行比较器 | 展示 FPGA 并行优势，可对比软件基线 | 顺序判定（作为对比组） |
| 显示缓冲 | 行缓冲 + 双缓冲 | 避免撕裂、控制 BRAM 占用 | 全帧缓冲（BRAM 不够） |
| 工程管理 | Tcl 脚本重建 | 可复现、可交接 | GUI 手工建工程（禁止） |
