# 数据集说明（data/）

数据集按 [`docs/repo_conventions.md`](../docs/repo_conventions.md) 第 6 节的规则管理。

## 目录结构

```
data/
├─ README.md                 # 本文件
└─ gesture/
   ├─ left/                  # G1 左移
   ├─ right/                 # G2 右移
   ├─ fire/                  # G3 射击
   ├─ start/                 # G4 开始
   └─ idle/                  # 无手势 / 干扰动作（用于统计误触发）
```

## 采集要求

| 项目 | 要求 |
| --- | --- |
| 时长 | 每段 3–5 s |
| 数量 | 每种手势每场景 ≥ 30 段 |
| 光照 | 室内日光灯 / 台灯侧光 / 背光，共 3 种 |
| 背景 | 纯色墙面 / 杂物桌面，共 2 种 |
| 人员 | 2–3 名成员，特征尽量不同（身高、手型、衣袖颜色） |
| 命名 | `g<编号>_<手势>_<光照>_<背景>_<人员>_<序号>.mp4`，例：`g1_left_light01_bg02_p01_seq03.mp4` |

## 入库规则

- ✅ **允许入库**：降采样到 320×240、每类 2–3 段的**小样本**，单文件 < 5 MB。
- ❌ **禁止入库**：原始 640×480 完整视频、大批量帧序列（见 `.gitignore` 中 `data/gesture/**/*.mp4`）。
- 完整数据集的获取方式记录在本文件下方「完整数据集」小节（网盘链接或 Git LFS 说明）。

## 用途

1. B：Python/OpenCV golden model 的算法验证与阈值标定。
2. B：Vitis HLS 与 RTL 实现的输入激励与结果比对。
3. C：误触发率统计（`idle/` 与干扰动作样本）。
4. 全员：报告中的准确率、混淆矩阵与延迟数据来源。
