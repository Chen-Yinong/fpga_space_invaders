# 第零阶段

1. 两种手势控制：大拇指向左 大拇指向右
2. 主时钟：`clk_sys = 100 MHz`；像素时钟：`clk_pckl = 25.2 MHz`

## 两个关键问题

摄像头输入什么东西到“手势识别模块”


| **信号名称**    | **方向** | **位宽** | **对应时钟**   | **含义与工作机制**                                             |
| ----------- | ------ | ------ | ---------- | ------------------------------------------------------- |
| `cam_pclk`  | Input  | 1 bit  | —          | 摄像头像素时钟（约 24MHz），整个手势处理流水线的**基准驱动时钟**。                  |
| `rst_n`     | Input  | 1 bit  | `cam_pclk` | 异步复位，低电平有效。                                             |
| `cam_vsync` | Input  | 1 bit  | `cam_pclk` | **场同步信号**。拉高（或拉低）代表一帧画面的开始/结束。                          |
| `cam_href`  | Input  | 1 bit  | `cam_pclk` | **行有效信号**。高电平代表当前正在扫描有效像素行。                             |
| `cam_de`    | Input  | 1 bit  | `cam_pclk` | **数据使能（Data Enable）**。高电平代表当前时钟周期的`cam_data`是真实有效像素。    |
| `cam_data`  | Input  | 16 bit | `cam_pclk` | **像素颜色数据**。标准 RGB565 格式（`[15:11]`红,`[10:5]`绿,`[4:0]`蓝）。 |

“手势识别模块输出什么东西给游戏本体模块”


| **信号名称**        | **方向** | **位宽** | **目标时钟**             | **含义与工作机制**                                                                                          |
| --------------- | ------ | ------ | -------------------- | ---------------------------------------------------------------------------------------------------- |
| `gesture_cmd`   | Output | 4 bit  | `clk_sys`/`clk_game` | 0000 开始 0001暂停 0010 继续 0011重开 0100 向左 0101 向右 0110 不动 虽然目前打算一直不停的喷子弹来降低难度，但还是暂且预留：0111开始射击 1000 暂停射击 |
| `gesture_valid` | Output | 1 bit  | `clk_sys`/`clk_game` | **更新使能脉冲**。每处理完一整帧（约 30Hz\~60Hz），产生一个持续**1 个时钟周期的脉冲**，通知游戏机“请读取新的操作指令”。                              |
