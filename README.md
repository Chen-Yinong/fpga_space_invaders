# 新增的文件夹“is-it-possible-to-ai-it-perfect"

`cam_game，cam_game_optiflowverison这两个工程由Codex撰写，展示了效果相当不错的两个成品。另外三个文件夹是按键版游戏和两个手势识别模块（屏幕显示处理后画面，LED灯显示左或右）。`

## 基本设计

1. 手只区分三个状态：停止或移动速度小于某阈值为停，“明显”向左，激光炮台以一固定速度速度向左，“明显”向右，激光炮台以一固定速度速度向右
2. 开始暂停继续一个按键 key3，重开一个按键 key4，无声音，手势控制左右
3. 玩家控制位于屏幕底部的激光炮台（Laser Cannon），仅能左右横向平移移动。射击不停进行不用按钮控制，玩家控制左右，n条命（数字n-0显示在左上角，0时游戏结束）。炮台上方设有 4 座掩体（Bunkers）。既能阻挡敌人的下落炸弹，也会阻挡玩家向上射击的激光。掩体被任何一方的子弹击中都会被局部炸出缺口并逐渐瓦解；外星人方阵若降落至掩体高度，会直接将触碰到的掩体部分“碾碎抹除”。
4. 屏幕上方排列着 5 行、每行 11 只，共 55 只“外星人”，向下移动的同时左右移动，每只10分。外星人整齐向左或向右横向移动；当阵列最边缘的一只敌人触碰到屏幕边缘时，整个方阵会向下沉降一格，并掉头反向平移。外星人会随机向下扔炸弹，打中炮台扣一条命。
5. 只要有任意一只外星人成功触底降落到炮台所在的地表水平线，无论玩家此时剩余多少条生命，游戏立即判定失败。
6. 屏幕左上角计分（初始为0000）
7. 输出到HDMI显示器（板载有HDMI编码芯片，型号为SiI9134，具体引脚见厂家文档）
8. 屏幕角落“画中画”（PIP, Picture-in-Picture），显示二值化画面或者光流计算结果
9. 屏幕顶端随机刷出“神秘飞碟”：每隔随机时间，屏幕顶端以固定较快速度自左向右横飞一艘红色飞碟，击中飞碟可随机获得 50 / 100 / 150 / 300 分大奖
10. 经典街机分色（Color Strip Overlay）：（当年街机是在黑白 CRT 屏幕表面贴了彩色彩纸）顶部飞碟渲染为红色，外星人方阵区第 1 行浅蓝、23 行白色、45 行黄色；掩体与炮台区渲染为绿色。
11. 胜负结算画面 (Game Over / Win)：败：屏幕中央弹出灰色大字 GAME OVER；胜：全歼 55 只外星人后，弹出绿色 VICTORY! SCORE: XXXX。
12. 多关卡：当击杀计数器达到 55（即 alive_count == 0）时，不退出游戏，屏幕闪烁，显示Stage 2/Stage 3，重置血量，重置外星人阵列坐标到屏幕顶部（比上一次低一格），外星人下移和发射炸弹的计数器基准时间缩短，为了避免打不过，最后一关上调子弹射速，减少投弹频率。

## 有何区别

1. cam_game文件夹采用肤色识别二值化后计算质心的方法
2. cam_game_optiflowverison采用“光流法”
3. 因为二值化算质心版本操作效率较低，光流法操作效率较高，两者设定的血量与炮台移速与子弹射速与加速后的子弹射速均不同，游戏本体不能混用。
